# 大会プログラムPDFの取り込み

大会カードの「プログラムPDFを取り込む」からPDFを選ぶ。競技日と水路を確認し、選手名・所属・種目・競技番号・組・レーンを確認して、対象行を選択し保存する。申込一覧表から出場種目を先に登録しておく必要がある。

## 対応と照合

今回提供された山梨県秋季水泳競技大会の2段組・個人種目プログラムに対応する。10MB・50ページ以下、3000出走までを端末内で抽出し、保存は選択した1000件まで。画像PDF、リレー、別様式には未対応。

左段から右段、その次のページの順で競技見出し・組を引き継ぐ。空きレーンは除く。組の表記がない単一組は1組として確認画面に明示する。PDFに大会名・開催日の記載がないため、登録先・競技日はコーチが確認する。

氏名（全半角・空白を正規化）・性別・泳法・距離・水路で登録選手と既存の出場種目を照合する。同姓同名、未登録の種目は保存対象外。所属の確認も促し、初期状態では保存対象を未選択とする。「照合済みをすべて選択」も選手の所属確認後に使用する。

予選・準決勝・決勝・タイム決勝は別々に保存する。同じ出場種目・日付・ラウンドの再取込は既存値を更新し、行を重複させない。未選択やPDFから消えた出走情報の自動削除は行わない。別端末での変更は保存前の値・更新時刻と比較し、相違時には全件の保存を中止して再読み込みを促す。

## 保存と反映

`swim_meet_programs` は既存の出場種目に紐付け、PDF名・競技日・ラウンド・競技番号・組・レーンを保存する。PDF原本や他チームの選手名・所属は保存しない。申込タイム、自己ベスト、実測記録は変更しない。

既存のコーチ用出場種目のアクセスモデルと参加者登録を使うRLSを設定する。保存RPCはSECURITY INVOKER。未ログイン・anonの実行不可。公開QRのレスポンスと公開同意の範囲は変更しない。

1. `supabase/setup/meet-program.sql` を適用する（フロント公開より先）。
2. `index.html`、`meet-entry-pdf.js`、`meet-entry-import-ui.js`、`meet-program-pdf.js`、`meet-program-import-ui.js` を公開する。
3. 大会画面でPDFを選択し、対象行を確認して保存する。競技日は大会開始日から14日以内。

## 検証

- 提供PDF: 8ページ・34競技・383出走、組表記省略50件。PDF.js 5.6.205とPyMuPDFによる独立抽出で全383出走の氏名・所属・種目・競技番号・組・レーン・ページが一致。アプリの既存PDF.jsローダーは4.10.38を維持しており、そのバージョンでの実ブラウザ操作は未検証。
- `node tests/meet-program.cjs`: 段/ページ継続、組省略、空きレーン、予選/決勝、重複レーン拒否、大会/水路/同姓同名の照合、エスケープと表示、全インライン構文。
- 既存のmeet-entry-pdf、meet-schedules、public-meet-schedule、analysis-uiも成功。
- 本番DB上でDDLと保存RPCをトランザクション内で作成し、authenticatedロールで登録・訂正・古い更新の拒否・ラウンド分離・重複拒否・日付上限・anon実行不可を検証してROLLBACK。テスト後にテーブル・関数が残っていないことを確認。
- この検証では実PDFの出走情報を本番保存していない。提供PDFと実選手の抽出データは公開リポジトリに含めない。
