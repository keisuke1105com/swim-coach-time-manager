# 標準記録一覧

分析画面上部の「📋 標準記録一覧」から開く。選手を選ばず、大会・男女・水路・年齢/学年・泳法で絞り込み、種目×区分の表で確認する。初期表示はJOの男女・長短水路・全区分。横スクロール中も種目列を固定する。選択条件と開閉状態は同じページセッションの再描画で維持する。

## データと表示

アプリの判定で使う既存データを標準一覧へ渡し、数値の別コピーを持たない。

- JO: `STANDARDS`。男女・長短水路を展開。個人種目と登録済みリレーを含む。元データの年度と原資料情報は未登録と明示。50m背泳ぎ・平泳ぎ・バタフライの13歳以上はCS標準を使う既存ルールを説明する。
- 山梨県強化: `window.YAMANASHI_2026_STANDARDS`。2026年4月1日時点の学年、中1～高3、男女・長短水路。10分の1秒で表示し、記録の切り捨てを含む既存の突破判定条件を説明する。
- ゆめカップ: `YUME_CUP_STANDARDS`。2027年度予定、2026年度基準の継続使用であることを明示。A～Fを学年表記へ展開し、長短共通と表示する。
- 東京SC: `window.TOKYO_SC_STANDARDS`。2026年10月30日の年齢が基準。水路別の登録がないため「水路区分なし」と表示する。2027年予定分析でも2026年基準を暫定使用する旨を明記する。

未登録値は「—」。値の推定・水路変換・年度切替は行わない。出典URLが登録されていない場合、URLを推測せず資料名と未登録を記載する。この変更で既存の基準値や達成率計算は変更しない。

## 実装と検証

`standard-catalog.js` の表示モジュールと、`index.html` のデータ受け渡し・分析画面への入口から構成する。DB・認証・個人QR APIの変更はない。

`node tests/standard-catalog.cjs` で既存データとの全値一致、欠損・リレー・桁数、絞り込みと条件変更、空状態、HTMLエスケープを確認する。既存のanalysis-rankings・analysis-uiも実行。

ローカルChromiumのブラウザ検証では、実データを渡した同じ表示モジュールを使い、4基準の切替・条件変更・DOM再描画後の状態保持・キーボードフォーカス・390px画面の横スクロール・ページ幅からのはみ出し・JSエラーなしを確認。認証後の実データの書き込みは行っていない。
