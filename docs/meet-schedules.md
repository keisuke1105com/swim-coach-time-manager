# 大会の日別出場種目

第57回東京スイミングセンター招待の公式競技順PDFに基づき、第1日（2026-10-30）から第5日（2026-11-03）までの出場種目を競技番号順に表示する。

公式資料：https://www.tokyo-sc.com/wp/wp-content/uploads/2026/07/26.57invitation_swim_order.pdf

`meet-schedules.js` に大会ID・開始日・日別の種目と予選／タイム決勝番号を定義している。性別・泳法・距離から既存の出場種目を照合し、以後に申込PDFから追加した種目も自動で日別表示する。区分決勝や決勝の出場は確定情報として扱わない。未知の性別・種目は日程未照合として残す。他の大会は従来の選手別表示を保つ。

競技順PDFの汎用アップロード機能はこの変更には含まれない。別大会は公式順序に対応する定義を追加する。申込PDFの取込機能・記録・申込タイム・選手データ・DBスキーマは変更しない。

検証：`node tests/meet-schedules.cjs`。実際の出場データは公開テストに含めない。
